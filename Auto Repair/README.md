# Apex Auto — industry template 1

Sellable website demo for an **auto repair shop**, built for KTS General Solution LLC. The layout follows a modern automotive brand pattern: dark overlay navigation, full-bleed photography, cyan spec cards, a service catalog, and a black contact panel.

## Pages

- Home
- Services (Emergency Repairs, Brake Service, Diagnostics, Oil Changes, Engine Repair)
- Reviews
- About
- Contact

Primary conversion is **Call now**, with a floating phone button and a book-service form.

## Rebrand for a real shop

Edit `src/content.js` — shop name, phone, address, hours, copy, photos, and reviews all live there. No layout changes required for a first client pass.

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL Vite prints (typically `http://localhost:5173/`).
